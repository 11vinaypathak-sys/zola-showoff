# Reference intake

Drop files here, nothing else needed:

    ~/tools/zola-showoff/refs/          ← local only, never committed (the .gitignore blocks it)

## What to drop
- **Screenshots or saved images** of the Instagram posts and sites you mean. Not links:
  Instagram is look-only under its terms and I will not scrape it, and a link goes stale.
  Screen-record if it is motion; a 5–10 s .mov is fine.
- Name each file with one word for what you like about it, e.g. `type-scale.png`,
  `transition.mov`, `grid.png`, `palette.jpg`. One word is enough; I read the image.
- If a reference is a *site*, add the URL in `refs/SITES.txt` (one per line). I can read
  public sites directly.

## What I do with them
1. Read every file, write `docs/REFS-READ.md`: what each one is doing and which law it
   maps to (type, grid, motion, material). No copying; the grammar is extracted, the
   artwork stays theirs.
2. Mark which of the five inside pages and the orbit each reference informs.
3. Build, render, show you stills side by side with the reference.

## Not for this folder
Anything from the day job, any client work, anything with a real person's data.
